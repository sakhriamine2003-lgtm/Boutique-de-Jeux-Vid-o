# 🎮 GameVault - Plateforme de vente de jeux dématérialisés

## 📖 Description

GameVault est une plateforme web de vente de jeux vidéo dématérialisés développée dans le cadre d'un projet de formation. Elle permet aux utilisateurs d'explorer un catalogue de jeux, de rechercher et filtrer les jeux par genre, puis de gérer un panier d'achat interactif avec sauvegarde des données grâce au LocalStorage.

## 🎯 Objectifs

- Afficher dynamiquement un catalogue de jeux.
- Offrir une expérience utilisateur fluide et immersive.
- Permettre la gestion complète d'un panier d'achat.
- Concevoir une interface responsive en approche **Mobile First**.

---

## ✨ Fonctionnalités

- ✅ Affichage dynamique des jeux
- 🔍 Recherche par titre
- 🎮 Filtrage par catégorie (Action, RPG, FPS...)
- 🛒 Ajout au panier
- 📦 Page "Mon Panier"
- ➕ Augmentation de la quantité
- ➖ Diminution de la quantité
- 🗑️ Suppression d'un jeu
- 💾 Sauvegarde du panier avec LocalStorage
- 💰 Calcul automatique du prix total
- ✅ Validation de la commande
- 📱 Responsive Design (Mobile, Tablette, Desktop)
